- [ ] First launch and tray icon OK  
- [ ] Refresh matches Terminal Shape A when available  
- [ ] Shape B shows stale/unavailable — never fake %  
- [ ] Settings persist across relaunch  
- [ ] Notifications (if enabled) fire near threshold  
- [ ] Launch at login behaves as toggled  
- [ ] Quit vs hide-to-tray understood  
- [ ] Sleep/wake: refresh recovers  
- [ ] CLI path override works if PATH broken  
- [ ] Auth logout/login recovery works  
- [ ] No sustained high CPU while idle in tray  
- [ ] Logged annoyances in daily observation log  
- [ ] Filed issues with issue template
