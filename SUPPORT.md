# Support

AI Tray is a solo-maintained open-source desktop companion. Support is best
effort.

## Where to get help

| Need | Where |
| --- | --- |
| Install / run | [docs/guides/installation.md](docs/guides/installation.md) |
| How to use | [docs/guides/user-guide.md](docs/guides/user-guide.md) |
| Troubleshooting | [docs/guides/troubleshooting.md](docs/guides/troubleshooting.md) |
| Known issues | [docs/release/known-issues.md](docs/release/known-issues.md) |
| Copilot provider | [docs/providers/github-copilot.md](docs/providers/github-copilot.md) |

| Security | [SECURITY.md](SECURITY.md) — **not** public issues |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What to include in a bug report

- AI Tray version (or commit SHA)
- Platform: macOS arm64 or Windows x64
- Provider involved (Claude Code, GitHub Copilot, or both)
- Steps to reproduce
- Expected vs actual behavior
- Relevant logs from the in-app Logs screen (redact secrets)

## Response expectations

There is no SLA. Issues and PRs are reviewed when the maintainer can. Duplicate
or incomplete reports may be closed with a pointer to docs.

## Out of scope

- Provider billing or account support (contact Anthropic / GitHub)
- Requests for undocumented or scraped APIs
- Cursor personal quota provider (see product decision PD-023)
